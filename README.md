# Smecz — landing page

Landing page aplikacji Smecz dla amatorów sportów rakietkowych (tenis, padel, squash, pickleball).

Statyczna strona: `index.html`, `styles.css`, `main.js` i folder `assets/` (GSAP + ScrollTrigger, Motion 14 — biblioteki dołączone lokalnie). Nie wymaga budowania.

Podgląd lokalnie:

```bash
python3 -m http.server 4173
```

Zdjęcia: Unsplash (autorzy wymienieni w stopce strony).
